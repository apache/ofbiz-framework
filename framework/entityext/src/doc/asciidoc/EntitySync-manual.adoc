== Introduction to Entity Synchronization
OFBiz no longer synchronizes data between databases: the remote push and pull and the offline export and import of
EntitySync were removed. What remains is the data model and the timestamps it relies on.

An EntitySync record, with its EntitySyncInclude and EntitySyncIncludeGroup records, describes a set of entities by
name, package or entity group, with include, exclude and always rules. The Webtools XML Data Export page can use such
a set to choose the entities to export: enter the EntitySync ID in its EntitySync field.

The four fields (lastUpdatedStamp, lastUpdatedTxStamp, createdStamp, createdTxStamp) are added to each entity and
automatically populated, so that the records created or updated since a given time can be found, for example with the
"records updated since" option of the XML Data Export page. The no-auto-stamp attribute tells the Entity Engine not to
add these stamp fields and not to set them when creating and updating the entities. It is false by default.

When saveEntitySyncRemoveInfo is set to true in general.properties (it is false by default), the primary key of each
removed record is saved in the EntitySyncRemove entity. The cleanSyncRemoveInfo job deletes these records once they are
older than the largest keepRemoveInfoHours of the EntitySync records.
